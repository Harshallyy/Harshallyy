### 🔹 2. FundFlow

A campaign and donation management application focused on campaign management, verification, and AI-assisted functionality.

- 🔐 Implements authentication and role-based access control concepts.
- 📋 Provides REST APIs for campaign management and verification.
- 🤖 Integrates Spring AI with Ollama and the Mistral model for intelligent campaign assistance.
- 🏗️ Uses a layered MVC architecture.

**Tech Stack:** Java 21 · Spring Boot · Oracle AI Database 26ai · Spring Security · JWT · Spring AI · Ollama · Mistral
